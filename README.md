#Chrome Memory Limiter / Расшириение для Chrome которое помогает контролировать кол-во потребления памяти

Cross-platform Chrome extension for controlling memory consumption and tab limits, with an optional native RAM helper. Кроссплатформенное расширение для Chrome, которое ограничивает потребление памяти и количество открытых вкладок, с опциональным нативным помощником для мониторинга RAM.

🇬🇧 English
What it does

Chrome Memory Limiter helps keep your browser fast by monitoring how much RAM and how many tabs it uses. When you go over your set limits, the extension can warn you, suspend inactive tabs, or block new ones from opening — so Chrome stops eating all your system's memory.

Features:

Set a maximum number of open tabs
Set a memory usage threshold
Automatic suspension of inactive/background tabs
Real-time dashboard showing current memory and tab usage
Optional native helper app for more accurate system-level RAM stats
Installation

Since this extension isn't published on the Chrome Web Store, install it manually:

Download this repository — click Code → Download ZIP, or run:
   git clone https://github.com/YOUR_USERNAME/chrome-memory-limiter.git
Unzip it if needed.
Open Chrome and go to chrome://extensions
Turn on Developer mode (toggle in the top-right corner)
Click Load unpacked
Select the extension folder (the one containing manifest.json)
The extension icon should now appear in your toolbar — set your limits from the dashboard.
Requirements
Chrome 121 or newer

🇷🇺 Русский
Что делает

Chrome Memory Limiter помогает браузеру не тормозить, отслеживая потребление оперативной памяти и количество открытых вкладок. Когда лимиты превышены, расширение может предупреждать, «замораживать» неактивные вкладки или блокировать открытие новых — чтобы Chrome не съедал всю память компьютера.

Возможности:

Ограничение максимального числа открытых вкладок
Порог по использованию памяти
Автоматическая приостановка неактивных/фоновых вкладок
Дашборд в реальном времени с текущим потреблением памяти и числом вкладок
Опциональный нативный помощник для более точной статистики по системной памяти
Установка

Расширение пока не опубликовано в Chrome Web Store, поэтому устанавливается вручную:

Скачай репозиторий — кнопка Code → Download ZIP, либо через терминал:
   git clone https://github.com/YOUR_USERNAME/chrome-memory-limiter.git
Распакуй архив, если скачивал zip.
Открой Chrome и перейди на chrome://extensions
Включи Режим разработчика (переключатель в правом верхнем углу)
Нажми Загрузить распакованное расширение (Load unpacked)
Выбери папку с расширением (там, где лежит manifest.json)
Иконка расширения появится в панели инструментов — настрой лимиты через дашборд.
Требования
Chrome версии 121 или новее
